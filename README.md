# TelegramBot
A Telegram bot that helps students prepare for Operating Systems exams by answering questions about memory management, processes, file systems, and other OS concepts.


Features
 Answers exam questions about Operating Systems

 Covers topics: memory management, processes, file systems, I/O management

 Supports both text questions and photo uploads

 Deployed on Yandex Cloud using Cloud Functions

 Uses YandexGPT for intelligent responses

Quick Start
Find the bot in Telegram: @cheatsheet_itis_2024_vvot23_bot

Send /start to begin

Ask any OS exam question like "Что такое управление памятью?"


Technology Stack
Backend: Python, Yandex Cloud Functions

AI: YandexGPT API

Storage: Yandex Object Storage

Infrastructure: Terraform, Yandex Cloud

Messaging: Telegram Bot API
